## Windows Key Mapping Summary

```
Mac Key            →   Windows Key
────────────────────────────────────
Cmd (⌘)            →   Ctrl
Option (⌥)         →   Alt
Cmd+Option+↑/↓     →   Ctrl+Alt+↑/↓
```

## Key Takeaways (Windows)

1. **`Ctrl+/`** is the commenting shortcut you saw in `05_Comments.js`.
2. **`Ctrl+Shift+P`** opens the Command Palette — learn this one first, it unlocks every VS Code action.
3. **`Ctrl+P`** is the fastest way to open any file — just start typing the name.
4. **`F12` / `Alt+F12`** let you jump to or peek at function/class definitions instantly.

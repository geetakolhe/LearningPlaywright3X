# Prompt Template

Copy and paste this:

```
Explain [CONCEPT_NAME] and save it as IQ_Notes/[FILE_NAME].md
```

Or simply say:

```
Explain [CONCEPT] and save it as IQ_Notes/<name>.md
```

## Examples

| Your input | What I create |
|---|---|
| `Explain HTTP vs HTTPS and save it as IQ_Notes/HTTP_vs_HTTPS.md` | `IQ_Notes\HTTP_vs_HTTPS.md` |
| `Explain let vs var vs const and save it as IQ_Notes/LET_VAR_CONST.md` | `IQ_Notes\LET_VAR_CONST.md` |
| `Explain Promise and save it as IQ_Notes/Promise.md` | `IQ_Notes\Promise.md` |

## Format of every file

- Definition
- Comparison table (like Source Code vs Byte Code vs Binary Code)
- Key takeaways

Explain [YOUR CONCEPT] in a table view with clear comparison columns. Use a simple code/file example to walk through each layer. Save it as a .md file inside the IQ_Notes folder. Follow the same visual style as Source_Code_ByteCode_Binary_IQ.md — breakdown table, example walkthrough, pipeline diagram, and TL;DR.

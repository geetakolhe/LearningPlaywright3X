# VS Code Commands — macOS Edition

**Definition:** Keyboard shortcuts for VS Code on macOS. `Cmd` = ⌘ (Command), `Option` = ⌥ (Alt/Option).

## macOS Key Mapping Summary

```
Windows Key        →   Mac Key
─────────────────────────────────
Ctrl               →   Cmd (⌘)
Alt                →   Option (⌥)
Windows/Start      →   Cmd (⌘)
Alt+Click          →   Option+Click
```

## Key Takeaways (macOS)

1. **`Cmd+/`** is the commenting shortcut you saw in `05_Comments.js`.
2. **`Cmd+Shift+P`** opens the Command Palette — learn this one first, it unlocks everything.
3. **Touch Bar Macs:** F5, F10, F11, F12 may require holding the `Fn` key.
4. **`Cmd+P`** is your fastest file opener — skip the mouse entirely.
